# gpsfree

GPS-free localisation benchmark. Algorithms get IMU, magnetometer, barometer and echo ranges plus a prior 3D map,
and must estimate their position without ever seeing ground truth. Currently scored on **drones over Yosemite**.

## Scoring rules

- **Error** is the 3D Euclidean distance between the estimate and the true position, sampled at 10 Hz.
- **Distance travelled** is the 3D arc length of the true path, so climbs and descents count.
- **Score** (the one ranked number): the mean of log₁₀(error) over every sample from 100 m travelled to the end of
  the route, with error floored at 1 m. That is the geometric-mean error along the whole flight: an order of
  magnitude, not tied to any checkpoint and with no assumption about how error grows. Median over routes × seeds.
  Shown in metres and as log₁₀; lower is better. A non-finite estimate scores ∞.
- **Diagnostics** (shown, not ranked):
  - *MAE per band*: mean error over 0–250, 250–500, 500–1000, 1000–2000 and 2000+ m travelled.
  - *Lost at*: distance travelled when error first exceeds 50 m (route length if never).
  - *Growth k*: slope of log error vs log distance — ≈3 raw IMU drift, ≈1 linear drift, ≈0 bounded.
  - `xy_rmse_m` / `z_rmse_m` in `results.json`.
- The rules live in `benchmark/suite.json` + `gpsfree/evaluate.py`. Changing either (or any route) changes the
  suite fingerprint and marks every existing result ⚠ stale until it is re-run.

## Submitting

```sh
uv run gpsfree fetch yosemite         # download + bake the world into data/worlds
uv run gpsfree new my_method          # copy a template into experiments/my_method
uv run gpsfree eval my_method         # run the suite, writes experiments/my_method/results.json
```

1. Commit `experiments/<name>/algo.py` and `results.json`, open a PR.
2. CI re-runs only the experiments the PR touches and fails if the committed `results.json` doesn't reproduce.
   Scoring worse never blocks a merge.
3. After merge, CI regenerates the leaderboard above and commits it to `main`. Don't edit it by hand.
