# gpsfree

GPS-free localisation benchmark. Algorithms get IMU, magnetometer, barometer, echo ranges (and step events for
walkers) plus a prior 3D map, and must estimate their position without ever seeing ground truth.

```sh
uv run gpsfree fetch                  # download + bake worlds into data/worlds
uv run gpsfree new my_method          # copy a template into experiments/my_method
uv run gpsfree eval my_method         # run the full suite, writes experiments/my_method/results.json
```

## Scoring rules

- **Error** is the 3D Euclidean distance between the estimate and the true position, sampled at 10 Hz.
  Horizontal (`xy_rmse_m`) and vertical (`z_rmse_m`) errors are reported as diagnostics only.
- **Distance travelled** is the 3D arc length of the true path, so climbs and descents count. It is the
  same for every platform: walking or driving over terrain counts the slope, and flying counts the climb.
- Errors are read at checkpoints of distance travelled (100, 250, 500, 1000 m), never at fixed times, so a drone
  and a walker are compared after covering the same ground.
- **Headline:** median error at 500 m over all routes × seeds of a world/platform group.
- **Fail:** error at 500 m above 10 % of distance travelled (50 m). A diverged or non-finite estimate counts as a fail.
- **Ranking:** separate tables per platform, ranked by the mean headline over worlds. Platforms are never mixed;
  a method is only ranked on the platforms it declares in `Navigator.platforms`.
- The rules live in `benchmark/suite.json` + `gpsfree/evaluate.py`. Changing either (or any route) changes the
  suite fingerprint and marks every existing result as stale until it is re-run.

## Submitting

1. Add `experiments/<name>/algo.py`, run `uv run gpsfree eval <name>`, commit `algo.py` and `results.json`.
2. Open a PR. CI runs the tests and re-runs your experiment; the PR fails if the committed `results.json`
   doesn't reproduce. Scoring worse never blocks a merge.
3. After merge, CI regenerates the leaderboard below and commits it to `main`. Don't edit it by hand.
